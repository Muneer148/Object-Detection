# Object Detection

Academic computer-vision project exploring the foundations of object detection through image loading, preprocessing, dataset inspection, and visualization.

> **Project type:** Academic / learning project

## Current workflow

```text
Image dataset
    ↓
Load / preprocess
    ↓
Inspect examples
    ↓
Visualize data
    ↓
Explore classification + localization concepts
```

The original notebook uses TensorFlow, TensorFlow Datasets, NumPy, Matplotlib, and PIL utilities.

## Status

The current repository represents coursework/exploration. It does **not** claim to contain a completed production-grade object detector or benchmarked detection model.
